# Objetos visuales de terceros

Este proyecto usa dos objetos visuales personalizados de Power BI, ambos con licencia MIT. Se incluyen sus versiones «standalone» oficiales, tal como las publican sus autores en GitHub. Las mismas piezas van también incrustadas en `../../Prj1_Almacen.Report/CustomVisuals/`, porque Power BI las guarda dentro del proyecto al importarlas.

| Archivo | Objeto visual | Origen | SHA-256 |
|---|---|---|---|
| `deneb.standalone.2.0.1.0.pbiviz` | Deneb 2.0.1 (Standalone Version) | [deneb-viz/deneb · release 2.0.1.0](https://github.com/deneb-viz/deneb/releases/tag/2.0.1.0) | `82d7a99766ab6e18d525b4f1ed7d5174e40233085ef540c9c0f9d8ad2a968679` |
| `HTML-Content-Standalone.2.0.0.pbiviz` | HTML Content 2.0.0 (Standalone) | [dm-p/powerbi-visuals-html-content · release 2.0.0.0](https://github.com/dm-p/powerbi-visuals-html-content/releases/tag/2.0.0.0) | `1f67297aa8b9e6debe2fb033e6a57f50c3c7cb669175476d760b3421af3e0248` |

Para usarlos en Power BI Desktop: activa «Desarrollar un objeto visual» (Archivo > Opciones y configuración > Opciones > Configuración del informe) y, en el panel «Visualizaciones», usa «Importar un objeto visual de un archivo».
